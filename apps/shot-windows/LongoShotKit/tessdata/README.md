Tesseract's trained models for reading text in Longo Shot for Windows (Windows' own recognizer has no Vietnamese):

- `vie.traineddata` from [tessdata_best](https://github.com/tesseract-ocr/tessdata_best) (accurate with Vietnamese marks)
- `eng.traineddata` from [tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast)
