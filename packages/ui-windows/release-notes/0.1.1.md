Fixes from the first PCs it ran on.

### What's new
- **Longo Shot:** the drawing toolbar keeps its own dark colors in light appearance too (buttons were lighting up white, and ✕ looked off).
- **Longo Shot:** after a capture the screen is bright again at once; Windows was fading the capture windows out.
- **Every app:** the menu's Settings… and Quit sit at its two corners, each as wide as its words.

### Early beta
The first Windows versions, built and checked automatically on Windows (tests, every page drawn). If something doesn't work, please [open an issue](https://github.com/ngolong1405/LongoKit/issues).

### Download
One `.exe` per processor, nothing to install (.NET is inside): **x64** for Intel / AMD, **arm64** for Snapdragon. Not signed yet, so Windows SmartScreen may warn before the first launch: **More info › Run anyway**. It opens in the notification area (by the clock). Requires Windows 10 (2004) or Windows 11.
