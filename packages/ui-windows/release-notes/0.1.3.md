Longo Shot saves to its own folder.

### What's new
- **Downloads\Longo Shot:** captures and recordings go to their own folder, made when the app starts, so they're easy to find (they went straight to Downloads). A folder you picked in Settings stays.
- **LongoKit** now has **Longo Share** too: files and text with your other devices nearby, as a chat with each one. Works with LocalSend.

### Install
1. Download the `.exe` for your PC: `x64` (most PCs) or `arm64` (Windows on Arm), and run it: no installer.
2. Beta, not signed yet: Windows may warn before the first launch (**More info › Run anyway**).
