Longo Share is now a chat with each device.

### What's new
- **A chat with each device:** the devices down the left (a green dot when it's around, a count of what's new), and on the right everything sent and received with the one you pick: text as messages, files as cards. Devices you've chatted with stay in the list, with their history.
- **No more pop-up windows:** files coming in show up in the chat with **Accept** / **Decline** (and *Always accept from this device*); a PIN is typed right there too. When something comes in while the window is closed, it opens on that chat.
- **Pictures shown:** a picture comes as a preview; click it to open it. Received files open with a click, or *Show in Explorer*.
- **Send:** type a message (Enter sends, Shift+Enter starts a line), click the paperclip, or drop files on the chat or on a device in the list.
- **Its own folder:** received files go to **Downloads\Longo Share**, made when the app starts (it was Downloads itself). A folder you picked stays. Settings shows where, and opens it.

### Install
1. Download `LongoShare-0.1.1-x64.exe` (most PCs) or `-arm64.exe` (Windows on Arm) and run it: no installer.
2. Beta, not signed yet: Windows may warn before the first launch (**More info › Run anyway**).
3. The first time, Windows Firewall asks about Longo Share: allow it on **private networks**, or other devices can't send to this PC.
