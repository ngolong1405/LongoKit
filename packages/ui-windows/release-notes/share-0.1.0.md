The first Longo Share: files and text between your devices nearby, compatible with LocalSend.

### What's in it
- **Devices nearby:** Macs and PCs with Longo Share, and phones, tablets and computers with [LocalSend](https://localsend.org), on the same Wi-Fi or network. Not found? Add one by its IP address.
- **Send:** drop files (or folders) on a device, or click it to pick some. Text too, from the clipboard.
- **Receive:** a window asks before anything comes in; *Always accept* trusts a device from then on. Files go to Downloads (or a folder you pick).
- **Optional PIN**, encryption (HTTPS, as LocalSend has it), history.
- In the notification area, on its own or in LongoKit.

### Install
1. Download `LongoShare-0.1.0-x64.exe` (most PCs) or `-arm64.exe` (Windows on Arm) and run it: no installer.
2. Beta, not signed yet: Windows may warn before the first launch (**More info › Run anyway**).
3. The first time, Windows Firewall asks about Longo Share: allow it on **private networks**, or other devices can't send to this PC.
